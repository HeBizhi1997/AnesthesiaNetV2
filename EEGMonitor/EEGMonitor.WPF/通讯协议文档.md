通讯协议文档
一、EEG 采集设备串口协议
1.1 物理层参数
参数	值
波特率	115200 bps
数据位	8
停止位	1
校验位	无
接收缓冲区	65536 bytes
1.2 数据帧结构
每帧固定 516 字节，格式如下：


┌──────────┬──────────┬──────────────────────┬──────────────────────┬──────────┐
│  Header  │  PktNum  │      Channel 1       │      Channel 2       │   Tail   │
│  1 byte  │  1 byte  │      256 bytes        │      256 bytes        │  2 bytes │
│   0x2A   │  0x01~04 │  64 × float32 LE     │  64 × float32 LE     │ 0x40 0x40│
└──────────┴──────────┴──────────────────────┴──────────────────────┴──────────┘
  [0]         [1]          [2 .. 257]               [258 .. 513]       [514][515]
字段	偏移	长度	说明
Header	0	1 byte	帧头，固定 0x2A
PktNum	1	1 byte	包序号，循环 0x01 → 0x02 → 0x03 → 0x04
Channel 1	2	256 bytes	EEG 通道1，64个 IEEE-754 float32 小端序
Channel 2	258	256 bytes	EEG 通道2，64个 IEEE-754 float32 小端序
Tail	514	2 bytes	帧尾，固定 0x40 0x40
1.3 数据率
项目	值
ADC 采样率	256 Hz
每包样本数	64 samples/channel
包发送频率	4 packets/s（包序号 1→2→3→4 循环）
每秒总字节	516 × 4 = 2064 bytes/s
1.4 ADC 原始值转换
设备使用 ADS1299 24位 ADC，float32 字段存储的是经过 ADC 量化后的原始比例值，客户端转换为 µV：


µV = raw_float32 × Vref / (PGA_Gain × (2²³ − 1)) × 10⁶
   = raw_float32 × 4.5 / (24 × 8388607) × 1,000,000
   ≈ raw_float32 × 0.02235 µV
参数	值
Vref	4.5 V
PGA Gain	24
满量程精度	≈ 0.02235 µV/LSB
1.5 帧同步与容错逻辑
接收端采用滑动窗口搜索帧头策略：


1. 在缓冲区内搜索 0x2A
2. 验证 [1] 字段: PktNum ∈ {0x01, 0x02, 0x03, 0x04}（否则跳过该字节重同步）
3. 验证 [514][515] == 0x40 0x40（否则跳过该字节重同步）
4. 校验通过 → 提取载荷，移除 516 字节，继续搜索下一帧
5. 缓冲区无 0x2A → 清空缓冲区
1.6 后处理滤波链（接收端）

原始 µV → [50 Hz 陷波, Q=30] → [0.5 Hz 高通] → [95 Hz 低通] → 送入算法
50 Hz 陷波：消除工频干扰
0.5 Hz 高通：去除 DC 偏移和低频漂移
95 Hz 低通：抗混叠（保留 BIS 所需 30–47 Hz 频段）
二、脉搏传感器串口协议（HKG-07D）
2.1 物理层参数
参数	值
波特率	19200 bps
数据位	8
停止位	1
校验位	无
工作模式	被动推送（无需主动发命令）
2.2 数据帧结构
每帧固定 5 字节，约 每 9 秒自动推送一次：


┌──────┬──────┬──────┬──────┬────────────────────────────────┐
│  0   │  1   │  2   │  3   │              4                 │
│ 0xF0 │ 0xC0 │ MLH  │ MLL  │    CKSUM                       │
└──────┴──────┴──────┴──────┴────────────────────────────────┘
字段	值/说明
0xF0	帧头字节1，固定
0xC0	帧头字节2，固定
MLH	BPM 高字节
MLL	BPM 低字节
CKSUM	校验和 = (0xF0 + 0xC0 + MLH + MLL) & 0xFF
2.3 BPM 解析

BPM = (MLH << 8) | MLL

示例: MLH=0x00, MLL=0x48 → BPM = 72
无信号: BPM = 0
