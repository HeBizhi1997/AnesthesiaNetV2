# MERIDIAN 麻醉睡眠监测系统 — 功能说明

> 版本：v1.0 | 日期：2026-05-26  
> 项目：EEGMonitor.AnesthesiaSleep (WPF, .NET 8)

---

## 一、系统概述

MERIDIAN 麻醉睡眠监测系统是一套**单页滚动仪表盘式**桌面客户端，连接脑电采集硬件（NSM / ADS1299）与 Python 推理后端（FastAPI + PyTorch），为麻醉睡眠门诊提供实时脑电监测、睡眠分期、血氧分析及临床操作记录功能。

### 系统拓扑

```
NSM/ADS1299 脑电采集器 ──串口──┐
脉搏血氧传感器 ────串口──────┼── WPF 客户端 ──HTTP── Python 推理服务
                               │                        (BIS/特征/SQI/熵)
模拟器 (内置) ─────────────────┘
```

### 界面布局

```
┌─ 顶部标题栏 ──────────────────────────────────────┐
│  系统名 | 患者ID | 科室 | 记录时长 | 服务状态 | 时钟  │
├─ 连接控制栏 ──────────────────────────────────────┤
│  串口/设备  |  患者信息  |  记录启停  |  复位/状态    │
├───────────────────────────────────────────────────┤
│  [当前分期卡片]   [TST] [睡眠效率] [觉醒指数] [SOL]  │
```

## 二、连接与硬件

### 2.1 脑电设备连接

| 功能 | 说明 |
|------|------|
| 设备选择 | ADS1299 (256Hz) / NSM (100-500Hz 自动检测) |
| 串口配置 | 端口号 (COM1-COM99)、波特率 (9600-921600) |
| 采样率 | NSM 自动检测，ADS1299 固定 256Hz |
| 通道数 | 2 通道 (Fp1, Fp2) |
| 脉搏传感器 | HKG-07D 指夹式，独立串口连接，提取心率和脉搏波 |

### 2.2 服务状态

- Python 推理服务健康检查（每 5 秒 Ping `localhost:8765/health`）
- 服务在线/离线实时指示灯
- 自动启动 Python 后端（PythonServiceLauncher）

## 三、实时监测

### 3.1 脑电波形

| 项目 | 规格 |
|------|------|
| 信号来源 | 真实硬件或模拟器 |
| 采样率 | 128 Hz |
| 窗口 | 256 点滚动（~2 秒） |
| 量程 | ±80 μV |
| 刷新率 | 最高 10 Hz（节流） |
| 曲线颜色 | 青色 (#00C8FF) |

### 3.2 催眠图 (Hypnogram)

| 项目 | 说明 |
|------|------|
| 功能 | 以时间为横轴、睡眠分期为纵轴的阶梯图 |
| 分期分类 | W(清醒)、N1(浅睡)、N2(中睡)、N3(深睡)、REM(快动眼)、体动 |
| 分类方式 | 规则引擎（基于频段功率、纺锤波密度、RE-SE差值、主频等）或未来ML端点 |
| Epoch 长度 | 30 秒（30 个 1-秒数据块累积） |
| 窗口 | 最近 120 个 Epoch（60 分钟） |
| 平滑 | 3-Epoch 多数投票防抖 |
| 底栏 | 彩色 Epoch 条带（每个 30s Epoch 一个竖条） |
| 图例 | 5 种颜色标识：灰(清醒)、橙(N1)、青(N2)、蓝(N3)、紫(REM) |

### 3.3 当前分期标识

- 大圆形色块 + 中文分期名称（如"N2（中睡）"）
- 置信度百分比（规则引擎输出 0-100%）
- 累计 Epoch 总数

### 3.4 睡眠统计（实时计算）

| 指标 | 英文缩写 | 单位 | 说明 |
|------|----------|------|------|
| 总睡眠时间 | TST | min | 所有 N1+N2+N3+REM 的累计时长 |
| 睡眠效率 | SE | % | TST / 总记录时间 × 100 |
| 入睡潜伏期 | SOL | min | 记录开始到首次进入睡眠的时间 |
| 入睡后清醒 | WASO | min | 入睡后所有 Wake 期的累计时长 |
| N1 占比 | N1% | % | N1 时间 / TST × 100 |
| N2 占比 | N2% | % | 同上 |
| N3 占比 | N3% | % | 同上 |
| REM 占比 | REM% | % | 同上 |
| REM 潜伏期 | REM Lat | min | 入睡到首次 REM 的时间 |
| 觉醒指数 | AI | /hr | 入睡后清醒次数 / TST(小时) |
| 伪迹 Epoch | — | 个 | 信号质量差被标记为 Movement 的 Epoch |

### 3.5 睡眠结构分布条

- 水平堆叠条，四段宽度按 N1%/N2%/N3%/REM% 实际比例动态分配
- 悬停显示各期百分比
- 下方逐项列出各期占比 + WASO + REM潜伏期 + Epoch总数 + 记录时长

## 四、血氧监测 (SpO2)

### 4.1 血氧指标

| 指标 | 说明 |
|------|------|
| 当前 SpO2 | 最新血氧值 |
| 平均 SpO2 | 全时段均值 |
| 最低 SpO2 | 全时段最低值 |
| ODI₃ | 氧减指数（≥3% 下降事件/小时） |
| ODI₄ | 氧减指数（≥4% 下降事件/小时） |
| T90 | SpO2 < 90% 的时间占比 |

### 4.2 脱氧告警

- 自动检测持续 >10 秒的 SpO2 下降事件
- 弹窗式红色告警横幅，显示当前最低 SpO2 值
- 基线自动学习（前 120 秒高值的 top 10% 平均）

### 4.3 SpO2 趋势图

- 180px OxyPlot 折线图
- Y 轴 50-100%，无小数
- 全时段历史，自动降采样（最多 300 点）

## 五、生命体征面板

位于脑电波形右侧，2×4 网格布局：

| 体征 | 显示格式 | 数据来源 |
|------|----------|----------|
| 心率 (HR) | 整数 bpm | 脉搏传感器 或 模拟器 |
| 血氧 (SpO2) | 整数 % | 脉搏传感器 或 模拟器 |
| 无创血压 (NIBP) | 收缩压/舒张压 mmHg | 模拟器（手动录入接口预留） |
| 平均动脉压 (MAP) | 整数 mmHg | 自动计算 (SBP+2×DBP)/3 |
| 呼吸频率 (RR) | 整数 bpm | 模拟器（手动录入接口预留） |
| 呼气末 CO2 (EtCO2) | 整数 mmHg | 模拟器（手动录入接口预留） |
| 体温 (Temp) | 1 位小数 °C | 模拟器（手动录入接口预留） |
| 记录状态 | 记录中/待机 + 时长 | 系统状态 |

## 六、临床操作

### 6.1 用药记录

- **录入字段**：药物名称、剂量、剂量单位(mg/mcg/g/mL/mg/kg/mcg/kg)、给药途径(IV/PO/IM/SC/IN/PR/IH)、输注速率(可选)、备注
- **时间线**：左侧表单录入 → 右侧时间线自动显示（时间戳 + 药名 + 剂量 + 途径）
- **删除**：支持删除误录条目

### 6.2 镇静评估

- **支持量表**：Ramsay (1-6)、RASS (-5 to +4)、MOAA/S (0-5)
- **操作**：点击量表类型按钮切换 → 点击数字按钮评分 → 自动显示对应描述（中文）
- **评估历史**：时间线显示，含时间戳 + 量表类型 + 评分 + 描述
- **描述已本地化**：全部翻译为中文临床术语

### 6.3 体位记录

- **6 种体位**：仰卧、俯卧、左侧卧、右侧卧、坐位、站立
- **当前体位**：大字显示
- **变更历史**：时间线显示每次变更

## 八、模拟测试模块

### 8.1 入口

顶部标题栏"模拟测试"按钮 → 弹出独立 ToolWindow

### 8.2 四个临床场景

| 场景 | 模拟内容 | 时长建议 |
|------|----------|----------|
| **自然睡眠** | 正常成人夜间睡眠：入睡→4-5个 NREM-REM 周期、SpO2 稳定 | 8h |
| **DISE** | 丙泊酚靶控输注：推注→维持→苏醒、REM 抑制、轻度呼吸抑制 | 50min |
| **OSA 筛查** | 周期性 SpO2 下降 8-20%、ODI₃ 15-40/hr、最低 SpO2 75-88% | 4-8h |
| **清醒镇静** | 咪达唑仑+芬太尼：BIS 65-85、Ramsay 2-3、约 60min 代谢 | 60min |

### 8.3 模拟数据

每 1 个模拟秒生成完整 ProcessedEEGResult：
- BIS 值（分期 + 药物效应 + 噪声）
- 5 频段功率（δ/θ/α/β/γ，归一化）
- 频谱熵 (SE/RE)
- 纺锤波密度（N2 高 3-8/min）
- SpO2（正常波动 + OSA 脱氧事件）
- 心率
- 合成脑电波形（6 频段正弦波 + 纺锤波包络 + 噪声，128Hz × 128 点）

每 5 秒额外发布 VitalSignsSnapshot（血压/呼吸/EtCO2/体温）。

### 8.4 控制

| 功能 | 说明 |
|------|------|
| 场景选择 | 下拉列表 + 中文说明 |
| 速度选择 | 1x / 2x / 5x / 10x / 20x / 60x 即时切换 |
| 启动/停止 | 独立控制 |
| 状态显示 | 运行状态 + 模拟时长(HH:MM:SS) + 当前倍速 |
| 预期指标卡片 | 4 个场景的典型参数预览 |

### 8.5 数据流转

```
SleepSimulator (后台线程)
    │
    ├─ ResultGenerated (每模拟秒)
    │       └─ SimulationViewModel ──Dispatcher.Invoke──→ ResultBroker
    │               │                                       │
    │               │          ┌────────────────────────────┤
    │               │          │                            │
    │               │    SleepStagingVM              SpO2TrendViewModel
    │               │    (累积30s→分期→催眠图)       (SpO2趋势+ODI)
    │               │          │
    │               │    EpochCompleted
    │               │          │
    │               │    SleepStatisticsViewModel
    │               │    (重算TST/SE/SOL/各期%)
    │               │
    │               └─ ShellViewModel (EEG波形缓冲+节流刷新)
    │
    └─ VitalSignsUpdated (每5模拟秒)
            └─ SimulationViewModel.LatestVitals
```

## 十、数据持久化

- **录制**：通过 IRecordingService 存储 raw_eeg.bin + processed.jsonl + session.json
- **回放**：通过 IPlaybackService 读取已存会话
- **复位**：清空所有界面缓存（分期/统计/血氧/用药/镇静/体位/脑电波形），不删除磁盘数据

## 十一、技术架构

### 11.1 项目结构

```
EEGMonitor.AnesthesiaSleep/
├── Models/           8 个模型文件 (SleepStage, SleepEpoch, SleepStatistics,
│                         DrugRecord, VitalSignsSnapshot, SleepReport, ...)
├── ViewModels/       9 个 VM (Shell + Staging + Statistics + SpO2Trend +
│                         DrugAdmin + Sedation + Position + Report + Simulation)
├── Views/            主窗口 ShellWindow + 模拟弹窗 SimulationDialog +
│                     ReportPreviewDialog + 9 个用户控件
├── Infrastructure/
│   ├── Messaging/    ResultBroker (发布-订阅总线)
│   ├── SleepStaging/ SleepStageRuleEngine (规则引擎分期)
│   ├── Simulation/   SleepSimulator (4 场景模拟引擎)
│   └── ReportGeneration/ ReportGenerator (JSON/CSV 导出)
└── Themes/           NightModeColors.xaml (夜间模式配色)
```

### 11.2 依赖

- **原项目引用**：EEGMonitor.WPF（复用所有 Services/Models/Infrastructure）
- **MVVM**：CommunityToolkit.Mvvm 8.2.2
- **图表**：OxyPlot.Wpf 2.1.2
- **DI**：Microsoft.Extensions.DependencyInjection 8.0
- **日志**：Serilog + 多 sinks

### 11.3 数据总线

`ResultBroker` 是核心发布-订阅总线，解耦数据生产（DataPipeline / SleepSimulator）与数据消费（各 ViewModel）。所有 UI 更新通过 `Dispatcher.Invoke` 确保线程安全。
