# 麻醉/睡眠监测 EEG 预处理 —— 流程与问题记录

> 记录日期:2026-05-30
> 硬件:ADS1299 单电极差分板(LK-M1299),COM6 @ 230400
> 软件:EEGMonitor.WPF(.NET8) + EEGProcessingService(Python FastAPI)

---

## 一、数据采集层(WPF → Python)

| 步骤 | 说明 |
|---|---|
| **串口接收** | 帧协议:`0xA5`(请求)/`0xAA`(响应)头,uint16 LE 长度,地址,命令(bit7 = R/W),XOR 头校验 + XOR 数据校验,`0x5A`/`0x55` 尾 |
| **解交织** | 板子**固定发 8 路 float32 交织**(忽略 chMask 请求),只有 **CH0** 是差分电极信号,其余 7 路恒为 `0.0` → 取 CH0 |
| **采样率** | 板子**忽略速率请求**,实际 **~250 Hz/通道**(总吞吐 ~2000 float/s ÷ 8)→ 上送 Python 标记 `fs=250` |
| **分块上送** | `DataPipeline` 按 ~1s 切块,经 HTTP `POST /process` 发给 Python 服务 |

> 注:厂商测试软件 LK-M1299 在同一块板上 CH1 显示干净脑电、频谱无 50Hz 主峰 —— 证明硬件与电极接触本身良好,问题都在采集/处理链路。

## 二、预处理管线(`eeg_preprocessor.preprocess()`,按执行顺序)

```
原始 CH0 chunk (250Hz)
   │
 ① 硬件诊断 _hardware_diagnostics()      ← 滤波前
   │   · DC 偏置、削顶/饱和检测(由数据范围推断 ADC 轨)
   │
 ② 因果流式宽带滤波 _sf_broad()           ← 状态(zi)跨块保持
   │   · 高通 0.5Hz (Butterworth 4 阶)
   │   · 50Hz 陷波 ×3 级联 (iirnotch Q30)
   │   · 低通 47Hz (Butterworth 4 阶)
   │   → filtered(连续、无块边界跳变)
   │
   ├─③ 成分波形 δ/θ/α/β/γ                 ← 各自流式带通(γ 收窄到 30–45Hz)
   │     → 显示用,【保留眨眼】
   │
   ├─④ raw_eeg = chunk − 均值             ← 显示用,【保留眨眼】
   │
 ⑤ 眨眼剔除 _deblink_for_power()          ← 仅用于能量估计
   │   · <5Hz 分量 + MAD 稳健阈值找眨眼核(K=4)
   │   · ±150ms 扩展后线性插值剔除
   │   · 安全阀:若 >50% 被标记 = 持续慢波态 → 原样保留
   │   → filtered_for_power
   │
   ├─⑥ 频带功率占比 _band_powers()         ← Welch PSD on 滚动 4s 缓冲(用去眨眼信号)
   │
   ├─⑦ DSA 时频谱 _dsa()                  ← spectrogram 限 0–40Hz(用去眨眼信号)
   │
 ⑧ 信号质量 SQI _sqi()                    ← 幅度 × 高频噪声 × 单频干扰,排除工频频段
   │
 ⑨ 信号诊断 _signal_diagnostics()         ← 幅度 / 主频 / 单频占比(干扰告警源)
   │
 ⑩ 设备交叉校验(仅 NSM 设备有此分支)
```

### 关键设计原则
- `raw_eeg` 与 δ/θ/α/β/γ 成分波形走**原始 `filtered`**(保留眨眼,符合临床观察习惯);
- 频带功率占比与 DSA 走**去眨眼版本**(避免眨眼把能量灌进 delta)。

### 频带定义(与 v13 训练特征一致)
| 频带 | 范围 |
|---|---|
| δ delta | 0.5 – 4.0 Hz |
| θ theta | 4.0 – 8.0 Hz |
| α alpha | 8.0 – 13.0 Hz |
| β beta | 13.0 – 30.0 Hz |
| γ gamma | 30.0 – 47.0 Hz(显示收窄到 30–45Hz 避边缘噪声) |

## 三、遇到的问题与解决方案

| # | 现象 | 根因 | 解决方案 |
|---|---|---|---|
| 1 | EEG 波形块边界跳变、γ 出现 46Hz 噪声 | 每块独立 zero-phase `filtfilt` → 块边界瞬变 + 47Hz 边缘/50Hz 肩部泄漏 | **因果流式滤波**,SOS 状态(`sosfilt_zi`)跨块保持;γ 显示收窄到 30–45Hz |
| 2 | 波形"没去工频",残留 50Hz | 单次 Q30 陷波只衰减 ~9dB(残留 ~8%) | 50Hz 陷波 **×3 级联**(因果,−21dB,残留 0.8%),逼近 filtfilt 零相位深度而无非因果延迟 |
| 3 | 顶部告警 "31.0Hz 干扰 占96%·非脑电",全屏 γ 红 | WPF 请求 `chMask=0x01` → `_streamChannels` 被 ACK 回显设成 1 → 8 路全当样本(7 个零填充)→ 50Hz 折叠成 ~31Hz,落进 β/γ 带,陷波抓不到 | WPF 端 **`_streamChannels` 钉死为 8**,不再从 ACK 推导;de-interleave 取 CH0 @ 真实 250Hz |
| 4 | δ 占比 81%(患者明明清醒) | 眨眼把巨量低频能量灌进 delta 带 | **眨眼检测 + 插值**,只作用于频带占比 / DSA;原始波形与成分波形保留眨眼 |
| 5 | 信号质量 SQI 锁死 **25%** | 50Hz 工频(占原始 96%)落在 ">47Hz 高频噪声"判据里 → hf_score 触底 0.25 | SQI 的噪声/总功率参考**排除工频频段**(50 + 100Hz 谐波 ±2Hz);真实 EMG(52–98、102–125Hz)仍计入 |
| 6 | "DC偏置 上万µV" 每秒刷屏报警 | 阈值 50µV 对这块输出大直流的硬件太敏感;DC 已被 0.5Hz 高通去掉,不影响脑电 | 删除独立 DC 告警;**只在 ADC 真饱和**(`HwIsSaturated`)时报硬件告警;DC 值仍返回供诊断 |

## 四、验证结果(用真实 COM6 采集数据离线复核)

| 指标 | 修复前 | 修复后 |
|---|---|---|
| 50Hz 残留 | 99% | **0.8%** |
| EEG / 工频比 | — | **+21 dB** |
| 滤波后幅度 | — | **24–37 µV**(生理范围) |
| δ 占比(含眨眼) | 95% | **65%**(α 由 3% 恢复到 17%) |
| δ 占比(真实持续慢波) | 98.6% | 98.6%(完整保留,不误删) |
| SQI | 25% | **94%** |

## 五、相关参数(可调)

| 参数 | 位置 | 默认 | 作用 |
|---|---|---|---|
| `BLINK_K` | eeg_preprocessor.py | 4.0 | 眨眼检测灵敏度(越小越敏感) |
| `BLINK_PAD_S` | eeg_preprocessor.py | 0.15 | 每个眨眼核两侧剔除宽度(秒) |
| `BLINK_MAX_FRAC` | eeg_preprocessor.py | 0.50 | 超过此比例判为持续慢波态,不剔除 |
| 50Hz 陷波级联次数 | `_build_stream_filters()` | ×3 | 工频抑制深度 |
| `STREAM_CHANNELS` | SerialPortService.cs | 8 | 板子固定交织通道数 |
