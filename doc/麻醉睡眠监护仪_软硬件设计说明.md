## 一、软件功能模块说明

> 软件为**单页滚动仪表盘式**客户端（无多标签切换、防误触），按临床工作流组织为 12 个功能模块。每模块统一给出：功能描述 / 临床意义 / 关键参数与输出 /（适用时）报警。

### 1.1 设备连接与信号质量诊断

- **功能描述**：脑电采集前端与指夹血氧模组的串口连接与配置；患者信息录入；记录启停；服务健康检查（推理服务在线/离线指示）。
- **信号质量诊断（SQI，四维度）**：平坦线检测、ADC 饱和检测、高频伪差检测、50Hz 工频干扰检测；电极阻抗检测与脱落/无数据检测。
- **临床意义**：信号质量差时自动提示并使算法进入"惯性模式"（冻结上次干净状态），避免噪声污染指标——优于传统"信号差即断开"策略。
- **报警**：电极脱落、阻抗过高、工频干扰、ADC 饱和。

### 1.2 实时脑电波形与频谱

- **功能描述**：多通道原始脑电实时波形 + δ/θ/α/β/γ 分频波形（滚动窗）；DSA 频谱热力图（0–40Hz × 历史时间）。
- **关键参数**：量程 ±80μV；波形刷新 ≤ 10Hz（节流，连续无丢帧）。
- **临床意义**：直观观察脑电节律演变（如诱导期 α 前移、深麻醉爆发抑制、N3 慢波）。

### 1.3 睡眠分期与催眠图

- **功能描述**：AASM 五分期（W/N1/N2/N3/REM + 体动）自动判读；催眠图（时间为横轴、分期为纵轴的阶梯图）；当前分期大色块 + 中文名称 + 置信度。
- **关键参数**：Epoch 30s；3-Epoch 多数投票平滑；窗口支持整夜浏览。
- **睡眠统计（实时计算）**：总睡眠时间 TST、睡眠效率 SE、入睡潜伏期 SOL、入睡后清醒 WASO、各期占比（N1/N2/N3/REM%）、REM 潜伏期、觉醒指数 AI、伪迹 Epoch 数。
- **临床意义**：从"麻醉监测"延伸为"麻醉睡眠监测"的核心模块，量化睡眠结构。

### 1.4 血氧与呼吸事件监测

- **功能描述**：SpO₂ 全时段趋势图；自动计算 ODI₃/ODI₄/T90、平均/最低 SpO₂；脱氧事件自动检测（基线自学习，持续 >10s 下降）。
- **临床意义**：围术期 OSA 筛查（临床指南要求），未诊断 OSA 患者术后并发症率升高 2–3 倍。
- **报警**：SpO₂ 低、脱氧事件（弹窗红色横幅 + 当前最低值）、呼吸暂停。

### 1.5 生命体征面板

- **功能描述**：网格化集中显示 心率(HR)、心率变异性(HRV)、无创血压(NIBP 收缩压/舒张压)、平均动脉压(MAP)、呼吸频率(RR)、呼气末 CO₂(EtCO₂)、体温(Temp)、记录状态。
- **关键参数**：MAP 自动计算 (SBP+2×DBP)/3；数值整数化显示。
- **报警**：HR 上/下限、NIBP 上/下限。

### 1.6 体动监测

- **功能描述**：下肢双通道肌电采集，识别肢体活动；统计体动次数、体动强度、周期性肢体运动（PLM）指数。
- **临床意义**：评估睡眠片段化、镇静下体动、麻醉浅化的体动前兆。
- **报警**：异常活动 / 频繁体动。

### 1.7 临床操作记录

- **用药记录**：结构化录入（药物名称、剂量、单位、给药途径 IV/PO/IM/SC/IN/PR/IH、输注速率、备注）；时间线自动显示；药物时间线可叠加于睡眠分期与血氧趋势，展示给药-效应关系。
- **镇静评估**：支持 Ramsay(1–6)、RASS(-5~+4)、MOAA/S(0–5) 量表，一键评分 + 中文描述；评估历史时间线。
- **体位记录**：仰卧/俯卧/左侧卧/右侧卧/坐位/站立，当前体位大字显示 + 变更历史（关联呼吸事件）。
- **临床意义**：支撑镇静药物剂量-反应研究、睡眠结构与血氧关联分析、体位相关 OSA 分析。

### 1.8 报告生成

- **功能描述**：一键生成麻醉睡眠综合监测报告。
- **报告内容**：患者信息与监测时段、睡眠结构统计（TST/SE/各期占比/催眠图）、SpO₂ 汇总（均值/最低/ODI/T90）、脱氧事件列表、用药/镇静/体位记录、信号质量评估。
- **导出格式**：PDF（打印签名归档）、JSON（数据交换/科研）、CSV（Excel 表格摘要）。

### 1.9 告警系统

- **功能描述**：声光报警，报警阈值可配置；按优先级分级与确认；报警自检与声光冗余。
- **覆盖**：SpO₂ 低、脱氧/呼吸暂停、HR/NIBP 越限、电极/信号异常。
- **合规**：参照 IEC 60601-1-8 报警系统通用要求设计。

### 1.10 数据记录与回放

- **功能描述**：完整存储原始脑电（raw_eeg.bin）+ 处理结果（processed.jsonl）+ 会话元数据（session.json）；支持离线回放分析；复位仅清空界面缓存、不删除磁盘数据。
- **关键指标**：原始数据 100% 可回溯；数据加密与完整性校验（产品化加固）。

### 1.11 长时监测与界面

- **功能描述**：≥8 小时连续稳定运行（睡眠门诊刚需）；夜间模式（琥珀/暗红低亮度配色，减少光污染影响患者入睡）；单页滚动仪表盘布局，避免术中误触。
- **界面**：全中文化，OxyPlot 图表坐标轴整数化。

## 二、硬件参数说明（重整）

> 本章为产品定型的**设计目标参数**（设计输入级别）。各模块给出定量指标，作为硬件研发、技术要求与注册检验的依据。

### 2.1 脑电采集前端（核心）

| 项目 | 设计指标 |
|------|----------|
| 通道数 | **≥ 4 通道（左额区 2 + 右额区 2）** + 参考电极 + 地电极；预留 8 通道及 EOG/EMG 扩展 |
| ADC | 24 bit ΔΣ（ADS1299 系列） |
| 采样率 | ≥ 256 Hz |
| 输入参考噪声 | ≤ 1 μVpp（典型，1–47Hz） |
| 共模抑制比 CMRR | ≥ 100 dB（含右腿驱动 RLD/DRL 共模抑制） |
| 输入阻抗 | ≥ 100 MΩ |
| 带宽 | 0.5–47 Hz，含 50 Hz 工频陷波与抗混叠滤波 |
| 输入动态范围 | 覆盖爆发抑制（近等电位）至清醒脑电幅度（±数百 μV） |
| 电极阻抗检测 | 支持，量程覆盖临床常用范围；脱落/无数据检测 |
| **输出** | 原始脑电波形、脑电频谱数据、电极连接/阻抗状态 |

> 双侧额区分别采集，便于评估左右脑活动对称性（α 不对称度）与提升睡眠分期判读稳健性。

### 2.2 脉搏血氧模组

| 项目 | 设计指标 |
|------|----------|
| 检测方式 | 指夹式探头（HKG-07D 级），独立串口连接 |
| SpO₂ 量程/精度 | 70–100%，精度 ±2%（70–100% 段，依 ISO 80601-2-61 临床标定） |
| 脉率 PR | 25–250 bpm |
| 其他输出 | 心率变异性（HRV/PRV）、灌注指数（PI）、脉搏波形 |
| **报警** | SpO₂ < 93% 报警；脉率上/下限报警 |
| **输出** | HR、HRV、SpO₂、PI |

### 2.3 血压监测（NIBP）

| 项目 | 设计指标 |
|------|----------|
| 参数 | 收缩压（SYS）、舒张压（DIA）、平均动脉压（MAP，自动计算） |
| 测量方式 | 按键测量 + 周期自动测量 |
| **报警** | SYS/DIA 上限、下限报警 |
| **输出** | SYS、DIA、MAP |

### 2.4 体动 / 肌电监测

| 项目 | 设计指标 |
|------|----------|
| 通道 | 下肢双通道肌电（EMG）采集 |
| 功能 | 连续监测、识别肢体活动状态、周期性肢体运动（PLM）检测 |
| **报警** | 异常活动 / 频繁体动报警 |
| **输出** | 肌电波形、体动次数、体动强度、PLM 指数 |

### 2.5 呼吸监测

| 项目 | 设计指标 |
|------|----------|
| 参数 | 呼气末二氧化碳（EtCO₂，capnography）、呼吸频率（RR） |
| 功能 | 实时监测 CO₂ 浓度与呼吸频率，连续监测 |
| **报警** | 呼吸暂停报警、CO₂ 浓度超限报警、呼吸频率异常报警 |
| **输出** | RR、EtCO₂ |

### 2.6 主控、通信与电源隔离

| 项目 | 设计指标 |
|------|----------|
| 主控单元 | 嵌入式 MCU/SoC：采集时序、数据缓冲、多通道交织解析、协议封装、上电自检 |
| 通信 | USB / 串口（院内）；预留蓝牙 / 网络（院外便携扩展） |
| 通信协议 | 帧同步、CRC 校验、读写位/DTR、错误重传（已完成实测修订） |
| 电源与隔离 | 医用电源；患者侧隔离（满足 GB 9706.1 漏电流/隔离耐压）；低噪声供电 |

### 2.7 显示与报警

| 项目 | 设计指标 |
|------|----------|
| 显示 | 脑电波形；心率/血氧/血压参数；呼吸参数；体动状态；睡眠分期与趋势 |
| 报警 | 声光报警；报警阈值可配置；优先级分级 |

### 2.8 安全、EMC 与合规摘要

| 类别 | 适用标准 |
|------|----------|
| 电气安全 | GB 9706.1-2020（IEC 60601-1） |
| 电磁兼容 | GB 9706.1-2 / IEC 60601-1-2 |
| 脑电专用 | GB 9706.226（脑电图机专用安全与基本性能） |
| 脉搏血氧 | ISO 80601-2-61 / 相应 GB 9706 系列 |
| 报警系统 | IEC 60601-1-8（参照） |
| 生物相容性（电极接触部分） | GB/T 16886 / ISO 10993 |
