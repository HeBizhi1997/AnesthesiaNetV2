## 一、BIS 脑电双频指数

### 1.1 算法原理

BIS (Bispectral Index) 是目前全球使用最广泛的麻醉深度监测指标，由 Aspect Medical Systems（现 Medtronic）于 1996 年推出。

**核心算法（三层结构）**：

```
原始EEG → 预处理 → 双谱分析 → 特征提取 → 统计模型 → BIS (0-100)
```

**第一层：双谱分析 (Bispectral Analysis)**

双谱是信号三阶统计量的傅里叶变换，用于量化 EEG 中不同频率成分之间的**相位耦合**（phase coupling）程度：

```
B(f₁, f₂) = E[ X(f₁) · X(f₂) · X*(f₁+f₂) ]
```

其中 X(f) 是 EEG 信号的傅里叶变换，E[·] 是期望值，\* 表示复共轭。

**临床意义**：麻醉状态下，大脑皮层神经元放电的同步化增强，导致特定频率（尤其是α和δ波）之间产生相位耦合。清醒状态下，这种耦合较弱。双谱分析是唯一能捕捉这种"相位一致性"的数学工具。

**第二层：特征提取**

BIS 算法从双谱和功率谱中提取 4 个核心子参数：

| 子参数 | 来源 | 生理含义 |
|--------|------|----------|
| **BetaRatio** | 功率谱 log(P_30-47Hz / P_11-20Hz) | 高频/中频比，反映镇静程度 |
| **SynchFastSlow** | 双谱 log(B_0.5-47Hz / B_40-47Hz) | 全频段双谱/高频双谱比，反映皮层同步化 |
| **Burst Suppression Ratio** | 时域 | 等电位（<5μV）时间占比 |
| **QUAZI** | 双谱 | 爆发抑制期间的近等电位指标 |

**第三层：模糊逻辑融合**

4 个子参数通过一个**模糊逻辑分类器**（fuzzy logic classifier）融合为单一的 BIS 值。该分类器使用从约 5,000 小时临床 EEG 数据中学习的规则库。

### 1.2 BIS 值的临床解读

| BIS 范围 | 麻醉深度 | 临床状态 |
|----------|----------|----------|
| 98-100 | 完全清醒 | 正常睁眼 |
| 90-98 | 清醒/轻度镇静 | 合作，反应正常 |
| 70-90 | 浅麻醉/深度镇静 | 对语言刺激反应减弱 |
| 60-70 | 全身麻醉（偏浅）| 意识消失，可能对强刺激有反应 |
| **40-60** | **适宜手术麻醉** | **推荐的全身麻醉深度** |
| 30-40 | 深度麻醉 | 意识完全消失，EEG 出现爆发抑制 |
| 20-30 | 过深麻醉 | 显著爆发抑制 |
| 0-20 | 爆发抑制/等电位 | 危险深度，循环可能被抑制 |

### 1.3 临床验证文献

| 研究 | 年份 | 关键发现 |
|------|------|----------|
| **B-Aware Trial** (Myles et al., *Lancet*) | 2004 | 2,463 例高危患者，BIS 指导组术中知晓率下降 82% |
| **B-Unaware Trial** (Avidan et al., *NEJM*) | 2008 | 1,941 例，BIS vs ETAC(呼末浓度)方案均有效，知晓率约 0.2% |
| **BAG-RECALL** (Avidan et al., *NEJM*) | 2011 | 6,041 例，BIS 方案与 ETAC 方案知晓率无显著差异 |
| **Cochrane 系统评价** (Punjasawadwong et al.) | 2014 | BIS 指导可降低术中知晓风险(OR 0.24)、减少麻醉药用量、缩短拔管和 PACU 停留时间 |

> **结论**：BIS 是目前唯一经过大样本 RCT 验证的麻醉深度 EEG 指标。本项目以 BIS 为回归目标，具有充分的临床证据支撑。

### 1.4 BIS 的已知局限

1. **个体差异**：同一 BIS 值在不同患者间对应的实际意识状态可相差 10-15 点
2. **药物特性差异**：氯胺酮（NMDA 拮抗剂）导致反常的 BIS 升高（因 β 波增加）
3. **信号干扰**：电刀、肌电(EMG)、起搏器可导致 BIS 伪差
4. **滞后性**：BIS 值变化滞后于真实脑状态约 15-30 秒（窗口平均算法特性）
5. **proprietary 黑箱**：Medtronic 的商业秘密算法，无法独立验证

## 二、频谱熵 (Spectral Entropy)

### 2.1 算法原理

频谱熵由 Datex-Ohmeda（现 GE Healthcare）开发，作为 M-Entropy 模块的一部分。其核心思想是用**信息论熵**量化 EEG 信号的复杂度/规律性。

**Shannon 频谱熵**：

```
SE = -Σ p_i · log(p_i)

其中 p_i = P(f_i) / Σ P(f_j)
P(f_i) 是频率 bin i 的功率谱密度
```

**物理直觉**：
- 清醒 EEG：高频成分丰富，功率分散在多个频段 → 高熵值
- 麻醉 EEG：功率集中于低频（δ/α）→ 低熵值
- 等电位：完全有序 → 熵趋近于 0

### 2.2 两个指标

| 指标 | 频率范围 | 临床含义 |
|------|----------|----------|
| **SE (State Entropy)** | 0.8-32 Hz | 反映皮层活动（EEG主导），对应催眠深度 |
| **RE (Response Entropy)** | 0.8-47 Hz | 包含 EMG 频段（32-47 Hz），反映面部肌电 |

**RE-SE 差值**：间接反映 EMG 活动水平（患者体动或疼痛反应的前兆指标）。

### 2.3 SE 值的临床解读

| SE 范围 | 状态 |
|---------|------|
| > 80 | 清醒 |
| 60-80 | 轻度镇静 |
| **40-60** | **适宜麻醉深度** |
| 20-40 | 深度麻醉 |
| < 20 | 爆发抑制/过深 |

### 2.4 与 BIS 的对比

| 维度 | BIS | SE/RE |
|------|-----|-------|
| 数学基础 | 双谱分析（三阶统计量）| 频谱熵（一阶信息论）|
| 算法透明度 | 商业黑箱 | 基于公开公式 |
| 对氯胺酮的反应 | 矛盾性升高 | 可能更准确反映麻醉深度(Viertiö-Oja 2004) |
| 对 EMG 的敏感度 | 可能误判 EMG 为清醒 | RE-SE 差值可分离 EMG |
| 大样本证据 | 强（多个 RCT）| 中等（RCT 规模较小） |

## 三、EEG 频段特征提取

### 3.1 标准频段划分

| 频段 | 频率范围 (Hz) | 生理关联 | 麻醉关联 |
|------|--------------|----------|----------|
| **δ (Delta)** | 0.5-4 | 深度睡眠(N3)、脑损伤 | 深度麻醉、丙泊酚高浓度 |
| **θ (Theta)** | 4-8 | 浅睡(N1)、冥想 | 诱导期、丙泊酚中浓度 |
| **α (Alpha)** | 8-13 | 放松闭眼、视觉皮层静息 | 前额 α 增强 = LOC 标志 |
| **β (Beta)** | 13-30 | 清醒注意、认知活动 | 浅麻醉残余、巴比妥类药物 |
| **γ (Gamma)** | 30-47 | 意识整合、感知绑定 | 指示 EMG 污染，不应被解读为 EEG |
| **σ (Sigma)** | 12-15 | 睡眠纺锤波 | N2 期标志，α2 受体激动剂(右美托咪定)典型 EEG |

### 3.2 功率谱估计方法

本系统使用 **Welch 法**（修正周期图平均）：

```
P(f) = (1 / K·L) · Σ_k | Σ_n w(n) · x_k(n) · e^(-j2πfn) |²
```

- 窗函数：Hann 窗，长度 4s (512 点 @ 128Hz)
- 重叠：50%
- 频率分辨率：1 Hz
- 相对功率：P_band / P_total（0.5-47Hz）

**优点**：Welch 法通过分段平均降低频谱方差，相比直接周期图法有更好的统计一致性。

### 3.3 SEF95（95% 频谱边缘频率）

```
∫₀^(SEF95) P(f) df = 0.95 · ∫₀^(∞) P(f) df
```

临床意义：SEF95 是 95% 总功率所在的最高频率。清醒时约 20-25Hz，深麻醉时降至 10-15Hz，爆发抑制时进一步降低。

## 四、高级 EEG 特征

### 4.1 排列熵 (Permutation Entropy, PE)

**数学定义**（Bandt & Pompe, *Phys. Rev. Lett.*, 2002）：

将信号 x(t) 嵌入到 m 维空间中，比较相邻值的排序模式：

```
PE(m) = -Σ p(π) · log₂ p(π)

其中 π 是 m! 种可能排序模式中的一种
p(π) = #{i | x(t_i) < x(t_i+1) < ... < x(t_i+m-1) 的排序模式 = π} / (N-m+1)
```

**本项目参数**：嵌入维数 m=6，延迟 τ=1，归一化到 [0,1]

**麻醉关联**：
- 清醒：排列模式多样 → PE ≈ 0.85-0.95
- 诱导期：EEG 波形趋于规则化 → PE 快速下降（最重要的 LOC 标志之一）
- 深麻醉/BS：极度规则 → PE < 0.3

### 4.2 Lempel-Ziv 复杂度 (LZC)

**算法**（Lempel & Ziv, *IEEE Trans. Inf. Theory*, 1976）：

将信号二值化（通常以中位数为阈值），然后计算生成该二值序列所需的最小"词汇表"大小：

```
LZC = C(n) / (n / log₂ n)

其中 C(n) 是 LZ76 压缩树中的不同模式数量
n 是序列长度
```

**物理含义**：衡量信号中可压缩/重复模式的多少。麻醉越深，EEG 越规律，LZC 越低。

### 4.3 慢振荡 (Slow Oscillation, 0.1-0.5 Hz)

**来源**：Steriade et al., *Science*, 1993 — 发现深度麻醉和 NREM 睡眠中的皮层慢振荡。

**临床意义**：
- 慢振荡是皮层神经元在深麻醉下产生的同步化"上下态"（UP/DOWN states）
- 与爆发抑制的病理生理机制直接相关
- 是比 DFA（去趋势波动分析）更可靠的深麻醉生物标志物

### 4.4 Delta-Alpha 相位-幅值耦合 (PAC)

**来源**：Purdon et al., *PNAS*, 2013 — 发现丙泊酚诱导下 δ 波的相位调制 α 波的幅度。

**数学表达**：

```
PAC = | Σ_t A_α(t) · e^(i·φ_δ(t)) | / (Σ_t A_α(t))
```

其中 A_α(t) 是 α 频段的瞬时幅度，φ_δ(t) 是 δ 频段的瞬时相位。

**丙泊酚特异性**：PAC 是丙泊酚增强 GABA_A 受体抑制的直接电生理指纹。PAC 值高 → 丙泊酚效应强 → 意识消失。

## 五、药代动力学-药效动力学 (PK/PD) 模型

### 5.1 Schnider 三室模型（丙泊酚）

**来源**：Schnider et al., *Anesthesiology*, 1998

丙泊酚的体内分布用三室模型描述：

```
dC₁/dt = -(k10 + k12 + k13)·C₁ + k21·C₂ + k31·C₃ + I(t)/V₁
dC₂/dt = k12·C₁ - k21·C₂
dC₃/dt = k13·C₁ - k31·C₃
```

其中 C₁ 是血浆浓度，C₂/C₃ 是快/慢外周室浓度，I(t) 是输注速率。

### 5.2 效应室模型 (Sheiner Effect Compartment)

**来源**：Sheiner et al., *Clin. Pharmacol. Ther.*, 1979

效应室浓度 CE 描述药物从中枢室转运到效应部位（大脑）的延迟：

```
dCE/dt = ke0 · (C₁ - CE)

ke0_prop = 0.456 min⁻¹  （Schnider 参数）
t½_ke0 = ln(2) / 0.456 ≈ 92 秒
```

**临床意义**：血浆浓度 C₁ 的变化（如推注）与 EEG 效应（BIS 变化）之间存在约 90 秒的滞后，这正是 ke0 所描述的药物穿过血脑屏障的时间。

### 5.3 Hill (Emax) 药效方程

```
E = E₀ · CE^γ / (CE50^γ + CE^γ)

E₀ = 基线效应（清醒 BIS ≈ 95-98）
CE50 = 产生 50% 最大效应所需浓度（Schnider: 3.4 μg/mL）
γ = Hill 系数（Schnider: 2.6，表示浓度-效应关系的陡峭度）
```

**验证数据**（本项目 97 个 VitalDB 丙泊酚案例）：

| 指标 | 结果 |
|------|------|
| Hill 方程 MAE | 13.1 BIS 点（群体均值） |
| CE-BIS 相关系数 | -0.567（滞后 90s） |
| CE-BIS 负相关文件占比 | 13/17 (76.5%) |
| 最优延迟中位数 | 90 秒（与 Schnider ke0 一致） |

### 5.4 阿片类协同效应 (Mertens 2003 交互模型)

```
CE50_eff = CE50_prop × (1 - β · CE_rftn / (γ50_rftn + CE_rftn))

β = 0.30（最大协同系数）
γ50_rftn = 2.0 ng/mL（半饱和效应浓度）
```

瑞芬太尼 CE = 4 ng/mL 时，丙泊酚 CE50 下降约 20%（3.4 → 2.7 μg/mL）。

### 5.5 MAC（七氟烷/地氟烷）等效

```
CE_eq = CE_prop + CE50_prop · MAC(t) / MAC_BIS_equiv

MAC_BIS_equiv ≈ 1.3（MAC=1.3 时 BIS≈40，与 CE=CE50 等效）
```

## 六、睡眠分期算法 (AASM 标准)

### 6.1 AASM 分期规则（2007 版，2023 更新）

美国睡眠医学会 (AASM) 标准将睡眠分为 5 期，以 30 秒为 1 个 Epoch：

| 分期 | 英文 | 中文 | 核心 EEG 特征 |
|------|------|------|--------------|
| **W** | Wake | 清醒 | α 节律(8-13Hz)主导（闭眼）、眨眼、高 EMG |
| **N1** | NREM 1 | 浅睡 | α 衰减<50%、θ(4-7Hz)出现、缓慢眼球运动(SEM) |
| **N2** | NREM 2 | 中睡 | K 复合波、睡眠纺锤波(12-14Hz, ≥0.5s) |
| **N3** | NREM 3 | 深睡/慢波 | δ 波(0.5-2Hz) ≥ 20% 的 Epoch，峰-峰幅 ≥75μV |
| **R** | REM | 快动眼 | 低幅混合频率 EEG、快速眼球运动、极低 EMG |

### 6.2 本项目分期规则引擎

本系统当前使用**基于特征的规则分类器**（无需额外训练模型），利用 5 个 EEG 特征判断分期：

| 特征 | 来源 | 使用方式 |
|------|------|----------|
| 相对 δ 功率 | Welch PSD | N3 判定：δ > 42% + EMG 低 + 纺锤波少 |
| 纺锤波密度 | 12-14Hz Hilbert 包络检测 | N2 判定：密度 ≥ 2.0/min + 中等 δ |
| RE-SE 差值 | 频谱熵 | Wake/REM 判定的高 EMG 替代指标 |
| β/(θ+α) 比值 | 功率比 | Wake 判定：> 0.4 + 高 EMG + 低 δ |
| 状态熵 (SE) | 频谱熵 | REM 判定：SE>20 + 极低 EMG + 低 δ |

**平滑机制**：3-Epoch 多数投票（滞后 1.5 分钟）防止单 Epoch 误判导致显示抖动。

**局限性**：额部 2 通道 EEG 无法检测 EOG（眼电）和颏 EMG，REM 和 N1 的分类准确度受限。升级到全导联 PSG 可解决。

### 6.3 关键区别：麻醉睡眠 vs 自然睡眠

| 维度 | 自然睡眠 | 麻醉（丙泊酚/七氟烷）|
|------|----------|----------------------|
| 入睡 EEG | α → θ 渐变 | α 前移 + β 激发（矛盾性激活）|
| 纺锤波 | 12-14Hz，正常形态 | 频率偏移（可至 10-12Hz），GABA_A 介导 |
| δ 波 | N3 期占 20-50% | 持续的 δ 慢波，占比可达 80%+ |
| REM | 规律出现（90min 周期）| 麻醉下通常缺失（除右美托咪定外） |
| K 复合波 | N2 期出现 | 药物抑制 |
| 慢振荡 | 0.5-1Hz，N3 期 | 0.1-0.5Hz，深麻醉 |

## 七、信号质量指数 (SQI)

### 7.1 四维度 SQI 算法

本系统使用加权多维度 SQI 评分：

```
SQI = min(Q₁, Q₂, Q₃, Q₄)

Q₁ = 平坦线检测：RMS > 0.5μV
Q₂ = 幅度检测：ADC 饱和占比 < 5%
Q₃ = HF 伪差检测：30-47Hz 能量占比 < 60%
Q₄ = 工频干扰检测：48-52Hz 窄带功率 < 总量的 40%
```

当 SQI < 0.5 时，LNN 核心进入**惯性模式**：冻结上次干净状态的隐藏状态前向传播，防止噪声污染 BIS 预测。这优于传统 BIS 的"信号差就断开"策略。

### 7.2 电刀 (ESU) 干扰对策

1. **中值滤波**（3 点窗口）：去除窄脉冲型电刀尖峰
2. **自适应陷波**：实时跟踪 50Hz 及其谐波（100/150Hz）
3. **SQI 联锁**：ESU 触发时自动标记 SQI 降级

## 八、爆发抑制检测

### 8.1 定义与机制

爆发抑制是大脑在深度麻醉或严重脑损伤下出现的特殊 EEG 模式：高幅爆发活动与近乎平坦的抑制交替出现。

**检测算法**（多阈值包络法）：

1. 计算 EEG 信号的 Hilbert 包络
2. 对包络应用 3 级阈值：2μV / 5μV / 10μV
3. 低于阈值的区间定义为"抑制段"
4. 计算抑制段占比 = BSR (Burst Suppression Ratio)

### 8.2 BSR 的临床意义

| BSR | 临床状态 |
|-----|----------|
| 0% | 无爆发抑制 |
| < 10% | 轻微爆发抑制（老年人常见于 BIS 30-40 范围）|
| 10-50% | 中度爆发抑制（深麻醉） |
| 50-80% | 重度爆发抑制 |
| > 80% | 接近等电位（极深麻醉/脑缺血） |

## 九、血氧饱和度与氧减指数 (ODI)

### 9.1 SpO2 脉搏血氧测定原理

基于 Beer-Lambert 定律，利用氧合血红蛋白(HbO2)与还原血红蛋白(Hb)在红光(660nm)和红外光(940nm)的吸收差异，通过光度比 (R/IR ratio) 计算 SpO2。

### 9.2 ODI 氧减指数

**定义**：每小时睡眠中血氧下降幅度 ≥3% (ODI₃) 或 ≥4% (ODI₄) 的事件数。

**检测算法**：
1. 维护 120 秒滑动窗口，取 top 10% 均值作为基线 SpO2
2. 实时比较当前 SpO2 与基线
3. 下降 ≥ 3%（或 ≥ 4%）持续 ≥ 10 秒 → 记为 1 次事件
4. ODI = 事件总数 / 记录时间(小时)

**临床阈值**（AASM 标准）：
- ODI₃ < 5/hr：正常
- ODI₃ 5-15/hr：轻度 OSA
- ODI₃ 15-30/hr：中度 OSA
- ODI₃ > 30/hr：重度 OSA

### 9.3 T90

**定义**：SpO2 < 90% 的时间占总记录时间的百分比。

OSA 严重度参考：T90 > 10% 通常提示中度以上睡眠呼吸暂停。

## 十、麻醉阶段分类

### 10.1 四阶段模型

| 阶段 | 英文 | BIS 典型范围 | EEG 特征 |
|------|------|-------------|----------|
| 术前 (Pre-op) | Pre-operative | 93-100 | 清醒脑电，α 闭眼节律 |
| 诱导 (Induction) | Induction | 100→40 | α 前移、β 激发、PE 快速下降 |
| 维持 (Maintenance) | Maintenance | 20-60 | δ 主导、可能 BS、SEF95 下降 |
| 复苏 (Recovery) | Recovery | 20→90 | δ 消退、β/γ 复现、PE 回升 |

### 10.2 阶段分类的意义

1. **分阶段 BIS 预测**：各阶段 EEG-BIS 映射关系不同，独立建模（PhaseGatedBISHead）可降低 MAE
2. **临床决策支持**：自动检测诱导/复苏过渡期，提醒麻醉医生关注关键时间窗口
3. **滞后效应建模**：复苏期 EEG 路径 ≠ 诱导期镜像（滞后效应），独立分类有助于模型学习

## 十一、本项目模型架构

### 11.1 AnesthesiaNetV3 (MERIDIAN)

```
输入层：
  ┌─ EEG 波形 (2ch, 512samples @ 128Hz = 4s 窗口)
  │    └→ WaveEncoder: 3层 Dilated CNN (32→64→128ch, kernel=7, dil=1/2/4)
  │       + BSR 层 (dil=16, 检测爆发抑制)
  │       → 128-dim 嵌入
  │
  ├─ 手工特征 (38-dim)
  │    └→ FeatureProjector: Linear(40→64)  [38 feat + 2 SQI]
  │       → 64-dim 嵌入
  │
  └→ Fusion: Concat → Linear(192→128) + LayerNorm + GELU

时序层：
  └→ LNNCore: GRU(2层, d_model=128, dropout=0.15)
     SQI Inertia Mode: SQI<0.5 时冻结隐状态

输出头：
  ├─ PhaseHead: 4分类 (术前/诱导/维持/复苏)
  ├─ StimHead: 刺激检测 (心血管响应标签)
  ├─ PhaseGatedBISHead: 4专家MLP × softmax门控 → BIS (0-100)
  └─ StimulationCorrector: 刺激时 BIS 矫正偏移

训练时额外模块 (推理时移除):
  ├─ PKEncoder: 6-dim 药物特征 → 64-dim
  ├─ VitalEncoder: 5-dim 生命体征 → 64-dim
  └─ CrossModalDistillation: BYOL 余弦相似度蒸馏
```

### 11.2 特征集（38 维，2 通道）

| 序号 | 特征 | 维度 | 计算方式 |
|------|------|------|----------|
| 0-4 | 5 频段相对功率 (δ/θ/α/β/γ) | per-ch | Welch PSD + trapz 积分 |
| 5 | 排列熵 (PE) | per-ch | Ordinal pattern, m=6, τ=1 |
| 6 | SEF95 | per-ch | 累积功率 95% 频率 |
| 7 | Lempel-Ziv 复杂度 | per-ch | 二值化后 LZ76 压缩比 |
| 8-10 | 爆发抑制比 (BSR 2/5/10μV) | per-ch | Hilbert 包络 × 3 阈值 |
| 11 | 1/f 谱斜率 | per-ch | log-log 线性拟合 (1-47Hz) |
| 12 | γ/EMG 能量比 | per-ch | P(30-47) / P(0.5-47) |
| 13 | σ 功率 (12-15Hz) | per-ch | 纺锤波频段功率 |
| 14 | 慢振荡 (0.1-0.5Hz) | per-ch | 深麻醉/深睡眠生物标志 |
| 15 | 零交叉率 | per-ch | 每秒钟穿越零线次数 / Nyquist |
| 16 | Hjorth Mobility | per-ch | sqrt(var(dx/dt)/var(x)) — 平均频率代理 |
| 17 | δ-α PAC | per-ch | δ波(0.5-4Hz)相位调制α波(8-13Hz)幅度的模长，丙泊酚 GABA_A 指纹 |
| — | α不对称度 | cross-ch | log(P_α_ch0 / P_α_ch1) |
| — | 平均 SQI | cross-ch | (SQI_ch0 + SQI_ch1) / 2 |
