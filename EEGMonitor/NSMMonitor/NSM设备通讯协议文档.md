# NSM 麻醉深度监护仪 — 串口通讯协议与数据内容文档

> 本文档依据 `EEGMonitor.WPF` 项目中 `NSMSerialService.cs` 的实际解析实现与
> `NSMDataPacket.cs` 的数据模型整理而成，描述 NSM 麻醉深度监护仪通过串口（UART/RS232）
> 上报的数据帧格式、各字节字段含义、数值换算方法与帧同步逻辑。
> 本文档同时作为 `NSMMonitor` 上位机接收端的实现依据。

---

## 一、物理层参数

| 参数 | 值 |
| --- | --- |
| 接口类型 | RS232 / UART |
| 波特率 | 115200 bps |
| 数据位 | 8 |
| 停止位 | 1 |

## 二、数据帧结构

每帧总长 **353 字节**，由「帧头 + 长度 + 载荷 + CRC」构成：

```
┌────────┬──────────────┬───────────────────────────┬──────────┐
│ Header │   Length     │          Payload          │   CRC    │
│ 1 byte │   2 bytes    │      载荷数据(含头/长度域)   │  2 bytes │
│  0x80  │ 0x5F 0x01 LE │   字段见 §三 字节映射表      │  CRC-16  │
└────────┴──────────────┴───────────────────────────┴──────────┘
  [0]       [1] [2]          [3 .. 350]                [351][352]
```

| 字段 | 偏移 | 长度 | 说明 |
| --- | --- | --- | --- |
| Header | 0 | 1 byte | 帧头，固定 `0x80` |
| Length | 1 | 2 bytes | 载荷长度，小端序（LSB, MSB），固定值 **351**（`0x5F 0x01`） |
| Payload | 0 | 351 bytes | 载荷区，从帧头算起共 351 字节，含各数据字段（见 §三） |
| CRC | 351 | 2 bytes | CRC-16 校验，多项式 `0x1021`，初值 `0xFFFF` |

> **说明**
> - 协议手册标称帧长为 355 字节（载荷 353），但**实际设备每帧比手册短 2 字节**，
>   载荷长度域上报值为 **351**，整帧 353 字节。接收端以实际值 351 为准。
> - 设备实际 CRC 算法与标准 CRC-16/CCITT 存在差异，**当前接收端跳过 CRC 校验**，
>   仅依靠帧头 + 长度域 + 整帧长度做帧同步与容错（详见 §六）。待厂商确认算法后再启用校验。

| --- | --- | --- | --- | --- |

| 12 | 1 | EventType | u8 | 临床事件类型（见 §五枚举） |
| 13 | 1 | **CSI** | u8 | 麻醉深度指数 0–99，等效 BIS；`0xEE`/`0xFF` = 无效 |
| 14 | 1 | **BS** | u8 | 爆发抑制比 0–100（%）；`0xFF` = 无效 |
| 15 | 1 | **SQI** | u8 | 信号质量指数 0–100（%）；`0xFF` = 无效 |

| 21 | 1 | AlarmLow | u8 | 下限报警阈值 |
| 22–121 | 100 | **EEG[100]** | i8 × 100 | EEG 波形，100 个有符号字节，直接为 µV（量程 ±127 µV） |
| 125 | 1 | **NOX** | u8 | 伤害感受 / 镇痛指数 0–99；`0xFF` = 无效 |
| 126 | 1 | DeltaPowerDb | i8 | δ 频带功率（dB，有符号） |

| 129 | 1 | BetaPowerDb | i8 | β 频带功率（dB，有符号） |
| 130 | 1 | GammaPowerDb | i8 | γ 频带功率（dB，有符号） |
| 131 | 1 | EOG | u8 | 眼动指数 0–100 |

## 四、电极状态位（BlockStatus，偏移 10）

| 位 | 掩码 | 字段 | 含义 |
| --- | --- | --- | --- |
| bit 1 | `0x02` | ElectrodeAlarm | 电极脱落报警 |
| bit 3 | `0x08` | ImpedanceHigh | 阻抗偏高 |
| bit 7 | `0x80` | ElectrodeInvalid | 电极失效 |

此外，当 `BlackImpedance >= 15` 或 `WhiteImpedance >= 15` 时，亦判定为阻抗过高。

| 值 | 枚举 | 含义 |
| --- | --- | --- |
| 0 | General | 一般 / 通用 |
| 1 | Induction | 麻醉诱导 |
| 2 | Intubation | 气管插管 |
| 3 | Maintenance | 麻醉维持 |
| 4 | Surgery | 手术 / 切皮 |
| 5 | Injection | 给药 / 注射 |

| 7 | EndMaintenance | 维持结束 / 苏醒 |
| 8 | Movement | 体动 |

仅当 `EventNumber > 0` 时事件字段有效。

## 六、数据率与采样

| 项目 | 值 |
| --- | --- |
| 每包 EEG 样本数 | 100 samples |
| 设备内部 EEG 采样率 | ≈ 100 Hz（实测，自适应） |
| 包发送频率 | ≈ 1 packet/s |
| EEG 转换 | 有符号字节直接为 µV（无额外比例换算），量程 ±127 µV |

**采样率自适应：** 接收端通过测量相邻数据包到达的时间间隔来反推真实采样率，
公式为 `采样率 = 100 样本 / 包间隔(秒)`，结果钳制在 50–500 Hz；连续采集 ≥5 包后锁定，
不依赖 UI 上手动选择的标称值。

## 七、帧同步与容错逻辑

接收端采用「滑动窗口搜索帧头」策略：

1. 在缓冲区内搜索帧头 `0x80`；
2. 移除帧头之前的无效字节；
3. 缓冲区不足整帧长度（353 字节）时，等待更多数据；
4. 校验长度域 `[1..2]`（小端）是否等于 **351**，否则跳过当前帧头 1 字节并重新同步；
5. （CRC 校验当前跳过）解析载荷、提取数据字段、对外发布 `NSMDataReceived`；
6. 从缓冲区移除已消费的 353 字节，继续搜索下一帧；
7. 缓冲区内无 `0x80` 时，清空缓冲区。

## 八、数据有效性判定

| 字段 | 无效标志 |
| --- | --- |
| CSI | `0xEE` 或 `0xFF` |
| BS | `0xFF` |
| SQI | `0xFF` |
| EMG | `0xFF` |
| NOX | `0xFF` |

无效时上位机应显示「---」并以灰色呈现，而非显示原始 255 值。

## 九、关键指标临床区间参考

### CSI（麻醉深度，等效 BIS）

| 区间 | 含义 | 颜色 |
| --- | --- | --- |
| < 40 | 过深麻醉 | 红 |
| 40–60 | 适宜区间（推荐手术区） | 绿 |
| 60–80 | 偏浅 | 黄 |
| > 80 | 清醒风险 | 红 |

### NOX（伤害感受 / 镇痛指数）

| 区间 | 含义 | 颜色 |
| --- | --- | --- |
| < 30 | 镇痛充分 | 绿 |
| 30–50 | 靶区 | 绿 |
| 50–65 | 关注 | 黄 |
| > 65 | 镇痛不足！ | 红 |

### SQI（信号质量）

| 区间 | 含义 |
| --- | --- |
| ≥ 70 | 信号良好 |
| 50–70 | 信号一般 |
| < 50 | 信号差，指标可信度低 |
