## 1. 产品概述与预期用途

### 1.1 产品定义

麻醉睡眠监护仪是一款以**前额脑电（EEG）为核心、融合脉搏血氧及多生理参数**的床旁智能监护设备，通过自研深度学习算法实时输出麻醉深度指数、麻醉阶段、睡眠分期及呼吸/血氧事件分析，供麻醉、睡眠、重症镇静等场景使用。

### 1.2 预期用途（Intended Use）

为临床医师提供患者**意识/麻醉深度水平、睡眠分期结构、血氧及呼吸事件**的连续监测与趋势显示，辅助：

- 手术室与麻醉恢复室的麻醉深度管理（防止术中知晓与麻醉过深）；
- 睡眠门诊的睡眠分期评估与睡眠呼吸暂停（OSA）筛查；
- ICU/无痛诊疗/DISE 等场景的镇静深度监测。

### 1.3 适用范围与禁忌

- 适用人群：需麻醉深度/镇静深度/睡眠监测的成年患者（儿童为后续扩展）。
- 使用环境：手术室、睡眠中心、ICU、内镜中心、麻醉门诊。
- 限制：监护结果为辅助参考，不单独作为诊断或治疗决策唯一依据；强电磁干扰、电极接触不良、严重肌电污染时指标可靠性下降，由信号质量诊断（SQI）提示。

### 1.4 医疗器械分类（初判）

- 主体按脑电/多参数监护，预判 **II 类医疗器械**；
- AI 麻醉深度/睡眠分期模块（SaMD，深度学习辅助决策）按《人工智能医疗器械注册审查指导原则》评估，若构成独立诊断决策可能升 **III 类**——立项阶段与药监部门预沟通确认。

## 2. 产品组成与技术架构

### 2.1 产品组成

| 组成 | 内容 |
|------|------|
| **采集硬件** | EEG 采集前端（ADS1299，2 通道 Fp1/Fp2，预留 8 通道）、脉搏血氧模组（HKG-07D 指夹式）、多参数接口 |
| **主控单元** | 嵌入式主控（MCU/SoC）+ 通信 + 电源管理 + 隔离 |
| **附件** | 一次性/复用电极、导联线、指夹探头、电源适配器 |
| **嵌入式软件** | 采集固件、通信协议、自检与阻抗检测 |
| **上位机软件** | EEGMonitor.AnesthesiaSleep（WPF/.NET 8）监测仪表盘 |
| **AI 推理软件** | Python FastAPI + PyTorch（EEG 预处理 + AnesthesiaNetV3 推理） |

### 2.2 系统拓扑

```
EEG 电极(Fp1/Fp2) ─→ ADS1299 采集前端 ─串口/USB─┐
指夹脉搏血氧(HKG-07D) ─串口────────────────────┼─→ 上位机(WPF)
多参数(预留) ──────────────────────────────────┘     │
                                                   HTTP/8765
                                                       │
                                              Python 推理服务
                                       (预处理 + 特征 + AnesthesiaNetV3)
                                                       │
                                        BIS / SE / RE / fNox / 睡眠分期 / SQI
                                                       │
                                          上位机实时显示 + 告警 + 记录回放
```

### 2.3 软件体系结构（IEC 62304 视角）

- **上位机（C#/WPF）**：MVVM 架构，ResultBroker 发布-订阅总线解耦数据生产与消费；Services 层（串口、记录、回放、Python 服务启动、事件标注）；ViewModels（分期/统计/血氧趋势/用药/镇静/体位/报告）。
- **推理服务（Python）**：preprocessing（滤波/陷波/熵/特征）、models（bis_predictor）、api（router/schemas），HTTP 接口。
- **软件安全分级**：依 IEC 62304，初判 **B 级**（失效可能导致非严重伤害——错误麻醉深度提示），高风险路径加固。

## 3. 产品技术要求与性能指标（设计输入）

### 3.1 脑电采集（核心）

| 项目 | 指标（设计目标） |
|------|------------------|
| 通道数 | ≥ 2（Fp1/Fp2），预留 8 通道扩展 |
| 采样率 | ≥ 250 Hz（ADS1299 当前 256 Hz） |
| ADC 分辨率 | 24 bit（ADS1299） |
| 输入参考噪声 | ≤ 1 μVpp（典型，1–47 Hz） |
| 共模抑制比 CMRR | ≥ 100 dB |
| 输入阻抗 | ≥ 100 MΩ |
| 电极阻抗检测 | 支持，量程覆盖临床常用范围 |
| 带宽 | 0.5–47 Hz（含工频陷波 50 Hz） |
| 输入动态范围 | 覆盖爆发抑制至清醒脑电幅度（±数百 μV） |

### 3.2 智能监测指标

| 指标 | 说明 | 目标 |
|------|------|------|
| BIS（麻醉深度指数） | 0–100，AnesthesiaNetV3 推断 | 对比金标准 MAE ≤ 5 |
| 麻醉阶段 | 诱导/维持/苏醒/术前 | 准确率 ≥ 95% |
| 睡眠分期 | W/N1/N2/N3/REM（AASM） | 与人工判图 κ ≥ 0.75 |
| 频谱熵 SE/RE | 状态熵/反应熵 | 与脑电状态一致 |
| 爆发抑制比 BSR | 三级阈值(2/5/10 μV) | 深麻检测 |
| 伤害指数 fNox | 伤害感受/刺激响应 | 事件相关性 |
| 纺锤波密度 | 区分自然睡眠/麻醉 | N2 期升高 |

### 3.3 血氧与生命体征

| 参数 | 指标 |
|------|------|
| SpO₂ | 70–100%，精度 ±2%（70–100% 段，依 ISO 80601-2-61） |
| 脉率 | 25–250 bpm |
| ODI₃/ODI₄ | 每小时氧减事件自动计算 |
| T90 | SpO₂<90% 时间占比 |
| 多参数（预留） | NIBP/MAP/RR/EtCO₂/Temp 接口 |

### 3.4 系统性能

| 项目 | 指标 |
|------|------|
| 端到端监测时延 | ≤ 2 s |
| 波形刷新 | EEG ≤ 10 Hz 节流，连续无丢帧 |
| 记录与回放 | 原始 EEG + 处理结果 + 会话元数据 100% 可回溯 |
| 信号质量诊断 | 低幅/工频/ADC 饱和/电极阻抗/设备交叉验证 |
| 告警 | BIS 过低(<40)/过高(>80)、SpO₂ 低、脱氧事件，声光提示 |
| 连续运行 | 睡眠场景 ≥ 8 h 稳定运行 |

### 3.5 安全、EMC、软件、网络安全

- 电气安全：GB 9706.1；EMC：GB 9706.1-2 / IEC 60601-1-2；脑电专用：GB 9706.226。
- 患者接触部分（电极）：生物相容性 GB/T 16886。
- 软件：IEC 62304 生命周期；GB/T 25000.51 质量。
- 网络安全：《医疗器械网络安全注册技术审查指导原则》，数据加密/访问控制/审计。
- 可用性：IEC 62366-1。

## 4. 现有研发基础（项目起点 TRL 4–5）

> 监护仪并非从零起步，已具备可运行原理样机：

- **采集硬件**：ADS1299（COM6，256 Hz，8 通道交织传输）与 NSM 模组、HKG-07D 指夹式 PPG（PR/PRV/SpO₂/PI）串口集成与**通信协议实测修订**完成（读写位/DTR、电极与无数据检测、工频干扰诊断）。
- **算法**：AnesthesiaNetV3（~62.3 万参数）含 WaveEncoder（扩展卷积 + 爆发抑制检测）、38 维特征投影、LNN/GRU 时序核（SQI 惯性）、阶段门控 BIS 头、刺激矫正器；VitalDB 验证 **BIS MAE 4.57**、阶段准确率 **98.6%**、刺激 AUC **0.816**。
- **上位机**：WPF 单页仪表盘——脑电波形、催眠图、11 项睡眠统计、SpO₂ 趋势 + ODI₃/ODI₄/T90 + 脱氧告警、生命体征面板、用药记录、镇静评估（Ramsay/RASS/MOAA-S）、体位记录、报告生成（JSON/CSV）、夜间模式、四场景模拟测试、会话记录与回放。
- **推理服务**：FastAPI + PyTorch，EEG 预处理（滤波/陷波/熵/特征）+ 模型推理 HTTP 接口（localhost:8765）。

本计划目标：将原理样机推进至**定型医疗器械产品 + 注册检验 + 临床验证 + 注册证**。

## 9. 数据采集与算法研发（M6–M24）

### 9.1 数据采集

- 数据源：VitalDB（手术麻醉，已用 1,749 例）+ Sleep-EDF/SHHS/MASS（睡眠）+ 合作医院前瞻采集（手术室/睡眠门诊 PSG 对照/镇静）。
- 采集 SOP + 知情同意 + 伦理审查；统一时间戳与多模态对齐。
- 金标准标注：BIS 监护仪/人工睡眠判图/事件，双人复核质控。

### 9.2 算法研发与冻结

1. 多任务训练：BIS + 阶段 + 睡眠分期 + 刺激 + PK/PD（三阶段课程学习）。
2. 域适应：手术室 → 睡眠门诊/镇静；个体化校正。
3. 评估：MAE、κ、ROC/AUC、Bland-Altman、子组（年龄/性别/BMI）偏倚分析。
4. **算法冻结**：锁定临床版模型，禁止训练后变更（满足注册一致性）。
5. 算法验证报告：训练数据描述、验证方法、性能、局限、再训练策略。

### 9.3 现有指标与改进

- 现状：BIS MAE 4.57 / 阶段 98.6% / 刺激 AUC 0.816。
- 待改进：诱导期 MAE 7.99、苏醒期 6.45（快速过渡区间），睡眠分期由规则引擎升级为 ML 模型。

## 10. 风险管理（ISO 14971，全程贯穿）

### 10.1 风险管理活动

- 风险管理计划 → 危害识别 → 风险评估 → 风险控制 → 剩余风险评价 → 受益-风险 → 生产与生产后信息。

### 10.2 关键危害与控制（示例）

| 危害 | 可能后果 | 控制措施 |
|------|----------|----------|
| BIS 指标错误偏低/偏高 | 麻醉过深/过浅，术中知晓 | SQI 自适应、双指标交叉、告警、说明书声明辅助参考 |
| 信号质量差未提示 | 误判 | 信号质量诊断 + 伪迹标记 + 冻结隐状态 |
| 电极脱落/阻抗高 | 无效监测 | 阻抗检测、脱落告警 |
| 漏电流/电气安全 | 患者伤害 | 隔离设计、GB 9706.1 验证 |
| 电磁干扰 | 指标跳变 | EMC 设计、IEC 60601-1-2 验证 |
| 数据泄露 | 隐私风险 | 加密、访问控制、脱敏、审计 |
| AI 误分期 | 临床误导 | 人工可复核、置信度显示、不作唯一依据 |
| 报警失效 | 延误处置 | 报警自检、声光冗余、优先级管理 |

### 10.3 剩余风险

逐项评估并在说明书/标签披露，建立生产后监督（PMS）与不良事件监测机制。

## 11. 设计验证与确认（V&V，M18–M28）

### 11.1 设计验证（Verification——是否满足设计输入）

逐项验证产品技术要求：EEG 性能、SpO₂ 精度、采样率、阻抗检测、电气安全、EMC、软件功能、报警、网络安全。形成验证报告与可追溯性矩阵。

### 11.2 设计确认（Validation——是否满足用户需求）

- 模拟/真实使用环境下临床适用性确认。
- 可用性确认（IEC 62366）：形成性测试（开发中）+ 总结性测试（定型后，含使用错误分析）。
- 软件确认：系统级、回归、网络安全（漏洞扫描/渗透测试）。

### 11.3 系统联调

监护仪 → 院内管理系统 → 远程小程序端到端数据链路联调与一致性核对。

- 送检机构：具备 CMA/CNAS 资质的医疗器械检验机构（如江苏省医疗器械检验所等）。
- 检验项目：
  - 电气安全 GB 9706.1；
  - 电磁兼容 GB 9706.1-2 / IEC 60601-1-2；
  - 脑电专用 GB 9706.226；
  - 脉搏血氧（ISO 80601-2-61 / 相应 GB）；
  - 软件（IEC 62304 / GB/T 25000.51）；
  - 网络安全；
  - 产品技术要求全项性能。
- 定型样机送检 → 检验报告 → 依意见整改复测 → 产品技术要求定稿。

## 13. 临床评价与临床试验（M28–M36）

### 13.1 临床评价路径

- 依分类与指导原则确定：同品种比对路径 + 临床试验（AI 模块通常需临床数据支持）。

### 13.2 临床试验设计

| 项目 | 内容 |
|------|------|
| 类型 | 前瞻性、多中心、对照 |
| 对照 | 麻醉深度——上市 BIS 监护仪头对头；睡眠分期/OSA——标准 PSG + 人工判图 |
| 场景 | 手术室麻醉、睡眠门诊、镇静 |
| 主要终点 | BIS 一致性（Bland-Altman、MAE）；分期 κ；OSA 灵敏度/特异度 |
| 次要终点 | 术中知晓率、报警准确性、可用性、不良事件 |
| 样本量 | ≥ 300（依把握度估算，power≥0.8、α=0.05） |
| 合规 | 伦理审查、知情同意、临床试验质量管理规范（GCP）、监查稽查、试验注册 |

### 13.3 临床试验报告

数据核查、统计分析、安全性与有效性结论、受益-风险评价。
